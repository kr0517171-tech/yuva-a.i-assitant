# Yuva A.I Assistant 🚀

Yuva A.I Assistant is an offline-first, lightweight, and multifunctional AI tool designed for fast calculations, problem-solving, expense tracking, resume building, and secure offline workflows.

- **Developer / Creator:** Kuldeep Rawat
- **Location:** Andhop, Palwal, Haryana
- **Institution:** MVN University, Palwal, Haryana
- **Course:** BCA (AI & ML)
- **Tech Stack:** Python, HTML, CSS, JavaScript

## 🏆 Key Features
- Offline-first AI processing
- Fast mathematical calculations and logic solving
- Integrated resume builder & expense management
- Built-in privacy and security controls
